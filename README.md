Arduino Based Hand Following Robot

Overview
This project is an Arduino-based robot designed to detect and follow hand movements using sensors and motor control mechanisms. The robot tracks the position of a hand and adjusts its movement accordingly.

Features
Hand movement detection
Real-time tracking
Arduino-based control system
Motor driver integration
Embedded systems application

Components Used
Arduino Uno
Ultrasonic/IR Sensors
Motor Driver Module
DC Motors
Chassis
Power Supply
Working
The sensors detect the position of the hand and send data to the Arduino. Based on the sensor input, the Arduino controls the motors to move the robot in the direction of the detected hand movement.

Applications
Robotics Learning
Automation Projects
Embedded Systems Experiments
